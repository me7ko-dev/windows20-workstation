# Windows 20 Workstation

Безкраен десктоп за Windows, в който агентите, терминалите и инструментите ти
живеят като прозорци на едно платно, а всичко се управлява от една командна
лента долу.

Идеята е същата като на [CNVS](https://cnvs.dev) — платно вместо ленти със
задачи — но CNVS е затворен код и само за macOS, затова това е написано от
нула и за Windows.

## Какво прави

- **Безкрайно платно** с местене и мащаб. Прозорците стоят в координати на
  платното, не на екрана, така че отдалечаваш и виждаш цялата си работа.
- **Истински терминали** през ConPTY. Прозорецът не е препис на разговора — той
  *е* работещата програма, затова Claude Code, git или каквото пуснеш се държат
  като в Windows Terminal.
- **Четири работни пространства** (01–04), всяко със свой тапет, своя папка и
  свой изглед. Запазват се между пусканията.
- **Командна лента (Ctrl+K)** — пишеш и десктопът го прави: отваря програма,
  създава терминал, намира прозорец по име, сменя тапет, отваря път или адрес.
  Търсенето разбира и български, и латиница (`vsc` намира VS Code).
- **Док с програмите, които наистина са на този компютър.** Приложението ги
  търси в PATH и в обичайните места за инсталация; ненамерените са затъмнени,
  а не скрити.
- **Бележки** на платното — планът стои до агента, който го изпълнява.

## Какво НЕ прави (и защо)

- **Не вгражда чужди GUI програми.** Windows няма поддържан начин прозорец на
  друг процес да се пресади в нашия. Затова VS Code, Cursor, Chrome и Explorer
  се пускат като собствени прозорци, а на платното стои карта за стартиране,
  вместо празна рамка, която се преструва.
- **Няма глас още.** Командната лента е построена около таблица от команди
  точно за да може гласовият слой после да превежда речта към *същите* команди,
  вместо да си измисля действия.

## Стартиране

```bash
npm install
npm run rebuild   # построява node-pty за тази версия на Electron
npm start
```

`npm run rebuild` е отделна стъпка нарочно: ако native модулът не се построи,
приложението пак тръгва — просто казва, че терминалите няма да работят, вместо
да откаже да се отвори.

За инсталатор под Windows:

```bash
npm run dist
```

## Клавиши

| Клавиш | Действие |
|---|---|
| `Ctrl+K` | командната лента |
| `Ctrl+T` | нов терминал |
| `Ctrl+N` | нова бележка |
| `Ctrl+1…4` | работни пространства |
| `Ctrl` + колелце | мащаб |
| влачене по фона | местене на платното |
| `Ctrl+0` | мащаб 100% |

## Структура

```
src/main/
  main.js        жизнен цикъл, прозорец, IPC
  preload.js     единственият мост между платното и машината
  pty.js         ConPTY сесии
  programs.js    каталог и откриване на инсталираните програми
  store.js       запис на подредбата
src/renderer/
  boot.js        сглобяване, клавиши, док
  canvas.js      безкрайното платно (pan/zoom)
  workspaces.js  пространства и живите прозорци
  node-window.js прозорец: местене, оразмеряване, фокус
  command-bar.js Ctrl+K лентата и таблицата с команди
  toast.js       съобщения
  nodes/         съдържание: терминал, бележка, стартер
```

Терминалите нарочно не се запазват на диск — процес не преживява рестарт, а
мъртва черупка, която изглежда жива, е по-лошо от празно платно.
